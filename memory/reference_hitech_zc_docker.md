The Docker image `ghcr.io/ravn/hitech` contains the `zc` compiler — HiTech C
for Z80.  This is the third compiler the project plans to compare against
(see `project_hitech_third_compiler.md`).  Use this image when an
investigation needs HiTech codegen alongside clang and z88dk SDCC; no need
to install or build HiTech locally.
