**ABSOLUT REGEL**: Efter enhver ændring kør byte-verifikation:

Kravet er **XIOS1 MATCH + XIOS4 MATCH** — ellers er ændringen ugyldig.

### RASM-86 encoding-faldgruber
Tre encoding-mønstre der SKAL bevares præcis som RASM-86 genererede dem:

| Mønster | RASM-86 (korrekt) | NASM-default (FORKERT) | Forskel |
|---|---|---|---|
| Direction-bit | `add_bp_bx` m.fl. via `rasm86.inc` | `add bp, bx` | 1 byte opcode |
| JMP near/short | `jmp near .ret` (E9, 3 bytes) | `jmp short .ret` (EB, 2 bytes) | 1 byte |
| Instruktionssekvens | `add si, N` / `mov al, [si]` | `mov al, [es:si+N]` | +1 til +3 bytes |

### CCB-feltoffsets (verificeret mod XIOS1/XIOS4)
`CCB_CON_IDX=0x34`, `CCB_ACTIVE=0x35`, `CCB_WIN_LEFT=0x36`, `CCB_ROWS=0x42`, `CCB_COLS=0x44`.
**OBS**: `CCB_ROWS=0x42` og `CCB_COLS=0x44` — IKKE omvendt. DH=row sammenlignes mod 0x42.

### Strukturdata vs. instruktioner
`db 0xFF, 0xC0` i DPB-kontekst er **data** (al0=0xFF, al1=0xC0) — ikke `INC AX`.
Disassembler-kommentarer der ligner instruktioner kan vildlede — tjek konteksten.

### Hvad gik galt

Alle 8 fejl rettet. Bisect-metoden (git checkout + Docker build + cmp) fandt `c440223` som første fejl-commit på ~5 minutter.

### Lærdom

## 6. Session 2026-11-26 — Hvad er opnået

Baseret på **RC759 CPU Board Reference Manual (RCSL-99-0-00825)** og **Piccoline Programmer's Guide v2 Appendix A**:

### hardware.inc — korrektioner og tilføjelser
- **PPI Port B bit-positioner var FORKERTE** (off by 3 bits): `/NET IDENT`=bit5, `/RTC SEC SOURCE`=bit4, `/SOGE`=bit3, `MONOCHROME`=bit2, `22KHZ`=bit1 (korrekt per s.45-diagram)
- `PPI_PORTC_GFX_EN` → `PPI_PORTC_nGRAPHIC`: bit 6 er aktiv-lav (0=grafiktilstand)
- `FDC_CTRL_DDEN` → `FDC_CTRL_nDD`: 0=MFM/dual density, 1=FM/single density
- Tilføjet `PPI_PORTA_*`-bitmasks (cassette, iSBX, RAM ident, DPC) og `PPI_PORTB_*`-bitmasks
- `RTC_REG_RAM_BASE` → `RTC_REG_LATCH_BASE` (0x08-0x0F er latch-registre, ikke scratchpad)
- Tilføjet fuldt MM58167A latch-register sæt (`RTC_REG_LATCH_*`)
- Dokumenteret RC759 RTC I/O protokol: bit7=read-mode, bit5=read-pulse, bit6=write-pulse
- Tilføjet `PPI_CTRL_INIT=0x92`, `RTC_REG_TEST=0x17`

### xios_code.asm — dokumentation
- `rtc_1sec_notify` 0xC4-kommentar: bit 7 = SKUDÅRS-FLAG (bekræftet fra RC759 manual s.33)
- **INT 28H fn 26-42 og 50**: API-kommentarer (entry/return-registre) fra Piccoline Guide v2

### RSP-symbolisering
**rsp_pin_code.asm**: 178 erstatninger af rå DS-offset med navngivne equates:
- `pin_cur_ccb` (66×) — aktuel CCB far pointer
- `pin_cword` (18×) — sidst læst konsolinput
- `pin_pd_ptr` (18×) — Process Descriptor pointer
- `pin_drive_idx` (8×) — drev-index i scanneloop
- 18 øvrige variabler navngivet

**rsp_vout_code.asm**: 74 erstatninger:
- `vout_cur_ccb` (28×) — aktuel CCB far pointer
- `vout_q_start/end` (13×) — kø buffer bounds
- `vout_char_pend/attr_pend` (15×) — afventende tegn/attribut

Equate-definitioner tilføjet som header i `rsp_pin_data.asm` og `rsp_vout_data.asm`.
