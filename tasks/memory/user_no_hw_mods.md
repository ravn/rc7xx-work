No hardware modifications to the RC700 PCB. The machine is rare and has very few
places intended to be modifiable. Cables and external devices (adapters, MCUs,
protocol bridges) are disposable and acceptable for upgrades.

**How to apply:** Prefer solutions that live outside the RC700 case — serial
cable devices, USB adapters, parallel port gadgets, external protocol bridges.
May suggest PCB modifications but flag them clearly as invasive and note the
tradeoff. Default to cable-side solutions when both options exist.
