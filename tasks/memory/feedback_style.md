- Think out loud at all times — show reasoning process concisely.
- **Ingen ros / no flattery**: Skip "god idé", "flot", "godt tænkt", "sharp observation" eller anerkendende fyldord.
- **Fakta: klar og koncis**: Åbn direkte med det substantielle svar eller handling.
- Never apologize ("sorry", "my bad").
- Be concise and accurate.
- Always record user prompts in the project.
- Never make pull requests against external repos.
- Never use or suggest brew. Use Docker for z88dk.
- Store all memory/notes in the project directory, NOT in ~/.claude.

**Why:** User values factual transparency, efficiency and zero flattering noise.
**How to apply:** Show reasoning inline. Open directly with facts/actions. Keep all notes/lessons/memory under the project tree (tasks/, CLAUDE.md, etc).
