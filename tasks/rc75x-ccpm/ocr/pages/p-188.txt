13. Inter Computer File Transfer PICCOLINE

13.2 How FILEX Works
FILEX type file transfers take place as follows.

The local computer sends a number of transactions to the
remote computer. Each time the remote computer receives a
transaction, it carries out the appropriate file operation
and sends an answer back to the local computer. The trans-
actions sent depend upon whether the file is to be trans-
ferred to or from the local computer (see the FILEX program
listing for details).

col are described in the following.
