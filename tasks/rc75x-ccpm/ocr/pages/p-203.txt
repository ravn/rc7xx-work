Function 28
Read next data record from cassette tape.

Registers on entry:

AL 28
cx Max number of bytes to read
Dx Input buffer offset

Stack on entry:

+0 Input buffer segment

Registers on return:

Al Function result

= 0 ok
= 1 CRC error
= 2 no data on tape
= 3 no leader found
= 4 wrong record number
= 5 end of file
AH, BX Undefined
CX Number of bytes read
DX Offset of next byte in input buffer

Stack on return:
Unchanged

See 7.2.6
